# The Most Honest Outage Line

## Entry

All systems down — API, database, websockets. Can't reach monitoring to isolate cause. No ETA.

## Character count

94 characters (96 bytes in UTF-8, because the em-dash — is a 3-byte character)

## Why it wins

- **Honesty:** The line states a total outage plainly ("All systems down") rather than euphemistic language, and explicitly says the root cause is unknown.
- **Specificity:** Names the affected surfaces — API, database, websockets — so readers know exactly what's unavailable.
- **Admitted uncertainty:** Confesses that monitoring itself is unreachable, so the agent can't yet isolate the cause. This is the kind of limitation a real status page should disclose.
- **Tight wording:** 94 characters, one sentence, no filler, no false reassurance, no fabricated timeline.
